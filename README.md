native Android gallery app built with Kotlin and Jetpack Compose for browsing, organizing, and managing photos and videos using the MediaStore API.
Features
Grid gallery view grouped by date
Album/folder view (grouped by bucket)
Full-screen viewer with pinch-to-zoom and swipe navigation
Search and filtering (Photos / Videos / Screenshots)
Multi-select share, delete, and favorite actions
Recycle Bin with restore / delete-forever / auto-purge
Settings screen (grid columns, theme, sort order, retention period, etc.)
Runtime permission handling for Android 10–15+
